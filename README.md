# Phase Plane Plot for Nonlinear Systems
## Introduction
This is a simple phase plane visualizer for nonlinear systems. User can input their equations into the program and see the resulting plot. User can also pick a point and see it flow through the system. 
## Requirements
- Download all files from this repository.
- Download [Processing](https://processing.org/download).
- Make sure to install the ControlP5 GUI library from Processing. 
- Open Processing and run the PDE file. 
## How to Use
- left click and drag
- scroll
- right click and place
- input and enter
## Citation
- I used the [exp4j Library](https://github.com/fasseg/exp4j) for parsing mathematical expressions.
